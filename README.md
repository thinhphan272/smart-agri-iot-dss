# AgriGuard-IoT: Smart Plant Health & Eco-Stress Monitoring System
> Real-time IoT Eco-Stress Monitoring & Agricultural Decision Support System powered by LightGBM on 200,000 Big Data Records.

## 🛠️ Technology Stack
- **Frontend:** React.js (Vite), Lucide Icons, Glassmorphism CSS, QR Code WebSockets.
- **Backend:** FastAPI, WebSockets Real-time Hub, PostgreSQL (agri_iot_db), SQLAlchemy ORM.
- **AI / Big Data:** LightGBM Classifier (Precision 95.05%, Optimal Threshold T* = 0.34).
